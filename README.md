# Do your tests catch real errors?

A field notebook with measurements of my AI-assisted development workflow, from spec to commit: what was measured, what only has real use, and what still has no proof.

**Read:** https://arthurfigg.github.io/jardim-testes-que-pegam-erro/ (English: `?lang=en`)

- The tests were run by Claude Code at my request, on Python and TypeScript projects, between October and November 2026.
- The English translation was done by Gemini, with automatic validation and a spot check (I did not review the whole translation).
- Each note's badge shows how well it is proven. Several results come from one project and one round.
- The workflow is at https://github.com/ArthurFigg/claude-dev-flow
